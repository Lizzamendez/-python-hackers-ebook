# 🐍 Python Hackers: Dominando Automações

**Autor:** Lizza Mendez  
**Plataforma:** DIO (Desafio de Projeto: Criação de eBook com IA)  

## 📖 Sobre o Projeto
Este repositório faz parte do desafio da DIO, no qual criei um eBook original sobre **automações com Python** utilizando IA generativa para auxiliar na estrutura e no conteúdo.

O objetivo é mostrar, de forma prática e criativa, como o Python pode ser usado para automatizar tarefas e aumentar a produtividade de desenvolvedores e entusiastas de tecnologia.

## 📂 Estrutura do Repositório
- `ebook.md` → eBook completo em formato Markdown  
- `prompts.txt` → Todos os prompts usados na criação do conteúdo  
- `imagens/` → Imagens
- `README.md` → Este arquivo  

## 💡 Conteúdo do eBook
- Introdução: O poder das automações  
- Ambiente Hacker: Instalando e configurando Python  
- Scripts Ninja: Automatizando tarefas do dia a dia  
- Domine a Web: Web Scraping e APIs  
- Automatizando Arquivos e Pastas  
- Bots e Automações Inteligentes  
- Conclusão
